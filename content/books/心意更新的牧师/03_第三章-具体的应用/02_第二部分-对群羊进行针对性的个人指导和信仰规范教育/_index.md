# 第二部分 强烈推荐对群羊进行针对性的个人指导和信仰规范教育

在揭露我们的过犯和疏忽并为之哀伤悔改后，我们在未来的职责应该是一目了然的。上帝会禁止我们重新回到我们所忏悔的罪中，防止我们象从前那样疏忽大意。在此基础上，我想进一步地对你进行劝勉，要忠实地将你所承担的伟大职责履行出来。也就是说，要在你的教区和教会中，对会众中的每个人进行信仰规范教育和指导，通常是采用编辑《信仰教义问答》或《教义信条原则》这一类的小册子。

首先，我想说明一下从事这种职责所应有的动机。

第二，我想就一些针对这项职责的反对意见进行说明。

最后，我要给你们一些方向性的指导，形成清楚可循的章程，更好地去履行这一职责。
